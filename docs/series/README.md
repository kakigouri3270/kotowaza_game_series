# ことわざゲームシリーズ

日本語のことわざ・慣用句を、文字どおりの行動として遊ぶミニゲームシリーズ。

- [企画一覧](IDEAS.md)：原案2本と追加案10本。未採用の提案を含む。
- [制作記録・ロードマップ](ROADMAP.md)：初期リズム版から現在の一人称版までの制作記録。
- [馬の耳に念仏の構想](uma-no-mimi-ni-nenbutsu/CONCEPT.md)：馬側を操作して念仏から逃げる案。実装は未着手。
- [糠に釘の実装と遊び方](../../README.md)：このリポジトリで実装している第一作。

現在の第一作は、自由な位置とタイミングで釘を刺す3Dゲーム。制限時間・タイミングバー・得点・ランキングは外し、本数カウントと3か所の糠場めぐりを実装している。

2026-09-27時点のシリーズ資料を、ゲームのソースと一緒に確認できるよう収録した。古い制作記録より、リポジトリのREADMEに書かれた現在の仕様を優先する。
