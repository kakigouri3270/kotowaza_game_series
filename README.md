# 糠に釘 — ことわざ遊戯

ただただ糠に釘を打つ3Dブラウザーゲーム。2026-09-26制作。

## 遊び方

- 「60秒、打つ」で開始。
- クリック、タップ、スペースで金槌を振る。
- タイミングゲージの中央に目印が重なるとPERFECT。
- 60秒後に名前を入力して「記録する」で共通ランキングへ。
- 「自由に打つ」は時間制限なし。ランキングの対象外。
- 右上の音ボタンでミュート。

## 採点

一周期840ミリ秒。中央から58ミリ秒以内は100点、140ミリ秒以内は40点、それ以外は10点。同じ周期の追加打撃は0点。PERFECTとGOODが連続すると、コンボ数×2点を加算（最大100点）。周期を飛ばすかSOFTになるとコンボが途切れる。

## 実装

- Three.jsによる3Dの糠箱・金槌・釘・飛び散る糠。
- Web Audioによる打撃音と、連続成功で音高が変化する倍音。
- React / Vinext、Cloudflare Workers / D1。
- 点数は打撃時刻からサーバー側で再計算。開始から60秒の経過とプレイの所有者を検証し、同じ記録の再送は重複させない。
- サーバーに得点を保存。ブラウザー保存は表示名とミュートの設定だけ。
- ブラウザーからの時刻申告を使うため、競技向けの完全な不正防止は未実装。

## ローカルで制作を続ける

Node.js 22.13以上とnpmを使用。

1. npm ci
2. npm run build
3. node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_little_skaar.sql
4. npm run dev

手順3は新しいローカルDBに対して一度だけ行う。既存環境では適用済みの移行を繰り返さない。開発URLは起動時に表示される。

## 確認したこと

- 60秒チャレンジ、自由プレイ、打撃、効果音生成、ミュート。
- スコア・コンボの境界と、一周期一回の採点。
- スコア保存、順位表示、再送時の重複防止。
- 開始直後の不正な送信、他プレイの記録、異常な入力を拒否。
- デスクトップと390px幅の表示。
- WebMCPの状態読み取り、ランキング表示、不正引数の拒否。
