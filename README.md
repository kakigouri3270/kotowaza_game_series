# 糠に釘 — ことわざ遊戯

一人称で小さな作業部屋を歩き、好きな場所へ釘を刺す3Dブラウザーゲーム。2026-09-26更新。

プレイURL：https://nuka-ni-kugi.kakigoori2000.chatgpt.site

## 遊び方

- 「部屋に入る」で開始。マウス固定が使えないブラウザーではドラッグ操作に切り替わる。
- WASD：歩く。マウス・ドラッグ・矢印キー：見回す。
- 糠の表面へ中央の目印を合わせ、クリック・スペース・E・「釘を刺す」で一本刺す。
- スマートフォンは左の矢印で移動、画面をなぞって視点移動、右のボタンで釘を刺す。
- 手が届く範囲の糠だけに刺せる。部屋を歩いて別の側からも刺せる。
- 釘は少し揺れ・傾きを伴ってぬるっと沈み、最後には見えなくなる。
- Escまたは「ひと休み」で停止。メニューの「糠の前に戻る」で最初の位置へ。
- 右上の音ボタンでミュート。設定はブラウザーに保存する。

現在は時間制限・採点・ランキングのない自由プレイ。タイミングバーは撤去済み。ポイントとランキングの方法は後で追加する方針。

## 実装

- Three.jsの3D作業部屋、視点に追従する手と釘、粒状の糠、影。
- マウス固定とドラッグの両操作、タッチ移動、キーボード操作、机と部屋の衝突判定。
- 視線と糠の交点・距離・縁の遮蔽判定による自由配置。
- 約5〜6秒の滑らかな沈み込み、個別の傾き・揺れ・粒・くぼみ。長時間プレイでも釘の描画資源を解放する。
- Web Audioで柔らかな刺し込み音を合成する。音はユーザー操作後に開始する。
- React / Vinext、Cloudflare Workers。以前のD1記録とAPIは保存しているが、現在のゲームでは使用しない。
- WebMCPはread_game_stateでプレイ状態を読み取る。以前のopen_rankingsは撤去。

## 制作を続ける

Node.js 22.13以上とnpmを使用。

1. npm ci
2. npm run dev

開発URLは起動時に表示される。現在の自由プレイにはDB初期化は不要。
